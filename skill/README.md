# 查询工作流与字段参考

这里提供可复用的招聘信息查询说明。使用者可以直接阅读，也可以将其接入支持相同格式的工具。

| 文件 | 内容 |
| :--- | :--- |
| [查询工作流](jobradar/SKILL.md) | 根据问题选择搜索、日历、变化、比较与趋势命令 |
| [字段参考](jobradar/references/fields.md) | 岗位、招聘简章和日历的输出含义 |
| [查询示例](jobradar/references/examples.md) | 常见问题与命令组合 |

所有结果应附原始来源和数据时间；缺失值保持缺失。聚合简章与单个职位分别理解，空结果不能直接推断公司没有招聘。

命令安装见 [项目首页](../README.md)，MCP 接入同样使用本地数据和共用查询层。
