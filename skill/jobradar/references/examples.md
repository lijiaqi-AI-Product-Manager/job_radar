# 示例

## "腾讯这周新开了什么岗？"

```bash
jobradar diff --days 7 --company 腾讯 --types open --limit 100
```

回答要点：数据截至时间；新开数量；按职类/城市归纳；列出代表性岗位及链接。若 `results` 为空，先用 `jobradar search --company 腾讯 --limit 1` 区分"库里没有腾讯"和"这周确实没有新岗"。

## "阿里和字节的算法岗要求有什么差异？"

```bash
jobradar compare 阿里巴巴 字节跳动 --category 算法 --per-company 8
```

回答结构：
1. 样本说明：每家取了几个岗位、数据截至何时。
2. 共同要求（引用原文关键词）。
3. 差异：分点列出，每点注明"阿里 JD 原文：……" / "字节 JD 原文：……"。
4. 你的归纳（明确标注为归纳），以及样本有限的提醒。

## "某某科技在招什么？"（库里没有）

`search` 返回空 → 回答："目前的数据里没有这家公司（数据截至 …）。本数据覆盖 `jobradar sources` 中列出的公司，建议直接查看该公司官网。"
