# 路线图

项目优先完善来源可信度、数据时效和日常查询体验。当前统计见 [覆盖说明](COVERAGE.md)，历史版本见 [更新日志](../CHANGELOG.md)。

## 已提供

- CLI 与 9 个 MCP 工具，共享本地 SQLite 查询层。
- 校招、实习与社招筛选，标题 / JD 搜索、公司简称匹配、去重和变更记录。
- 招聘日历、项目方向、网申日期与原始来源。
- 27 个注册适配器，覆盖共享招聘平台、自研站与公开聚合来源。
- GitHub Actions 数据采集、Release 快照、镜像和版本检查。
- 迁移锁、离线 fixtures、适配器契约、合规守卫与数据质量门禁。

## 主分支新增

- FTS5 trigram 索引与短词回退，保持原有搜索语义。
- 兼容既有客户端的公开数据库导出。
- 明示截止日、过期岗位首次入库与失败不关岗的回归修复。
- 才立方公开招聘简章，明确区分公告展示时效与企业网申期限。
- 更清楚的覆盖统计、最小入口证据与真实查询演示。

## 后续方向

| 方向 | 验收重点 |
| :--- | :--- |
| 更多合规公开来源 | 明确归属与访问规则，有当前正文样本和可回放测试 |
| 覆盖提升 | 固定 1,655 家分母，官方与聚合分口径；80% 为 1,324 家，当前尚未达到 |
| 日历时效 | 区分未知与明确截止，增加可靠起止日期 |
| 数据可靠性 | 明确采集时间、来源失败和字段缺失，避免误导在招状态 |
| 查询体验 | 以真实使用样例检验相关性、短词行为和性能 |
| 社区协作 | 改进问题模板、贡献文档与翻译 |

受登录、验证码、robots 或访问控制限制的入口保持停用。新增来源和功能按具体证据推进，不以数量替代质量。
