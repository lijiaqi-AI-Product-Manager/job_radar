# 按个人条件查找机会

接入MCP或skill后直接提出求职需求。工具返回的是候选与证据；是否满足资格、当前能否投递仍需核实原文。

## 城市与排除条件

“苏州、无锡都可以，但不要上海”使用城市并集与排除项：

```json
{"cities": ["苏州", "无锡"], "exclude_cities": ["上海"]}
```

任一城市包含上海的多城市记录会整条排除；城市未写仍为未知。
`exclude_companies`按确定主体排除，名称歧义时报错；未收录主体不会误删近似公司。
`exclude_keywords`仅排除标题字面量，不能代替“不要芯片方向”“不要求英语”等语义核验。
所有条件在结果截断前执行，`total`不是单页人工过滤后数量。

## 门店岗位与职类排除

明确指定校招或实习时，搜索和对比默认过滤标题明确的一线门店、房产经纪岗位；不限类型和社招查询保留原默认范围。过滤不删除记录、不改变岗位状态，也不判断用工资格。

想找门店实习、咖啡师等岗位时，直接告诉助手，工具设置`include_frontline=true`；CLI使用`--include-frontline`。其他类型可用`exclude_store=true`（CLI `--exclude-store`）主动过滤，不能同时要求包含和排除。专业岗位反例优先保留，例如“搜推导购产品实习生”“门店产品经理”“门店财务实习生”，不因包含“门店”或“导购”而自动过滤。规则保守保留不明确的标题，仍需阅读原文。

`frontline_filter`说明模式与排除的未折叠记录数。正文检索不复算被过滤数量时为`null`，不能补成0或用当前页估计；对比结果的`company_filters`按公司提供说明。

`exclude_categories`按固定职类大类、子类及已登记旧值排除，CLI可重复传`--exclude-category`。例如“财务”与“财务审计”使用相同别名并集。未知职类报错；职类缺失记录仍会保留，不能把排除参数视为完整语义排除。主动包含一线岗位不会取消显式职类排除。

## 届次、截止日与未知候选

有结果也要阅读`filter_coverage`和`hints`。其中`total/known/unknown`保留其他条件、仅移除对应字段筛选后复算，单位为未折叠记录。
全文检索暂不复算放宽后的数量，此时计数为`null`并明确标记作用域，不能编造漏岗数量。

```json
{"grad_year": 2027, "include_unknown_grad_year": true}
```

这会同时返回明确2027届与届次未标注候选，以`grad_year_match`区分。
未知记录可能实际接受多届，也可能完全不符合；不能直接说“符合2027届”。
不修改原始届次，不把多届范围压成某一个年份。
截止日未知不会自动归为未截止，日期范围仅命中明示日期。

日历`open_on`会保留窗口未知候选，`total`不能直接称为当日可投数量。
`window_counts`区分本页完整批次窗口与未知项；`scope=returned`表示并未汇总未返回页。
`confirmed_open_only=true`配合指定日期仅保留明确完整批次窗口，仍需核实实时投递状态。

## 资格冲突与原文

`qualification_evidence.degree`并列提供结构化学历与正文规则定位的候选要求。
`conflict=true`时需读取原句、查看正文时间并核实来源，不能只按结构化字段排除本科生，
也不能把一次正文提取当作所有学历条件的最终答案。其他资格没有统一结构化筛选。

社招渠道可以同时面向应届和毕业不久人群，渠道不等于资格；跨渠道查询不能静默改变推荐范围。
校招不代表无经验要求，出现英语不代表英语是硬性要求；“远程监控”不代表远程办公。
全文检索按词语共现匹配，结果的`text_match_semantics=literal_terms`不代表语义满足。

## 分组与计数

CLI/MCP默认折叠同公司、标题、城市集合、类型、届次、学历、部门、批次及截止日相同的记录。
`count_unit=folded_groups`表示展示分组，`variants`表示组内原条数；职责仍可能不同。
需要全部记录时设`dedupe=false`，CLI使用`--no-dedupe`。底层库调用保留原默认记录口径。
统计与变化事件仍以各自字段说明为准，不把展示分组数当作独立机会数量。

## 待遇和投递入口

实习僧详情明示的薪资区间、每周出勤和实习月数随正文保留；仅在下一次完整读取成功后进入快照。
其他来源未给出的待遇继续未知，不能从公司、岗位名或市场行情补值。

`url_scope=project_listing`表示需在项目列表按标题查找，不能称为直达该岗位。
`source_notice`是信息公告，可能还需寻找雇主申请入口；`unknown`不等于链接失效或已核实可投。
入口修正保留`recorded_url`，不会改变历史岗位状态、来源成功时间或停用状态。
