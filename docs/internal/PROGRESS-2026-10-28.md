## 1. 发现渠道：把「猜租户名」换掉

先把上一轮的做法量化了一遍，结论是**这条路已经走到头**：

- 40 家公司 × 5 个候选名（全拼 / 首字母 / 品牌英文）× 3 个平台（北森 / 大易 / 飞书）= 600 次请求，**0 命中**，耗时 272 秒。
- 原因不是探测脚本坏了（同一脚本打已知租户 `boe` 1003 岗、`gacrnd` 243 岗、`cntaiping` 1332 岗、`wuxiapptec` 632 岗全部正常），而是**剩下没建源的公司正是前几轮猜不中的残差**。

于是换成「先拿到候选主机，再定归属」。渠道实测结果：

| 渠道 | 结果 | 结论 |
|---|---|---|
| Google / searx 公共实例 | 400 / 403 / 429 | 不可用 |
| Bing（`www` / `cn`） | ICP 备案页、`site:` 被忽略 | 不可用 |
| 百度 / 搜狗 | 「百度安全验证」1428 B / 反爬页 | 不可用 |

定归属的硬规则（每条都真的挡下过东西）：

1. 门户 `<title>` 必须含中文公司名——标题是「招聘官网」「校园招聘」这类泛化文案的，一律不收；
2. 标题里出现「多品牌 / 共享门户 / 集团门户」的不收（`ys.zhiye.com` 一个池子挂多个品牌）；
3. 已知垃圾 slug 黑名单：`careers`、`campus`、`www`、`wecruit`、`portal-oss`、`itcast1`（「大学招聘门户」无归属）；
4. 同名不同主体要人工判：`camzhaopin`（国机 vs 中国机械总院）、`idea`（IDEA 数字经济研究院 ≠ 数字中国）、

5. 去重双键：`(adapter, tenant/host)` 与 `(adapter, 公司名去后缀)`，`beisen_host` 与 `beisen` 视为同一适配器。

## 10. 公开代码搜索拓源（源 1,129 → 1,310）与飞书两个真缺陷

### 10.1 渠道：为什么是公开代码搜索

这一轮之前，能规模化的渠道只剩子域枚举（`subdomain.center`）和 Common Crawl 索引，两者都已榨干；
搜索引擎（Bing/百度/搜狗/360/toutiao）要么直接封，要么结果页不再给明文 URL。新的突破口是
**公开代码搜索**：各公司的招聘门户配置、文档、前端代码里常直接写着 `xxx.zhiye.com`、
`xxx.jobs.feishu.cn`、`xxx.myworkdayjobs.com` 这类主机名，而 Sourcegraph 的公开代码搜索
（`https://sourcegraph.com/.api/search/stream`，SSE 流式返回）无需登录、可以直接按关键词检索。

产物：
- `work/code_host_harvest.py` → `work/code_hosts.json`：427 个北森主机、193 个 workday 主机、
  134 个飞书门户、33 个大易主机。
- 与已有源去重后按修正口径探活，`work/code_hits.jsonl` 272 条命中（北森 190 / 飞书 66 / 大易 16）。
- `work/apply_sd.py` 增加清洗与人工映射后落盘 **110 个北森源 + 1 个大易源**；
  `work/apply_feishu.py` 落盘 **26 个飞书门户**（全部有校招/实习岗）。

### 10.2 飞书门户 `website_path` 判定错（本轮最贵 bug）

飞书 ATSX 的门户可能挂在 `/campus`，也可能挂在 `/index`。适配器对 `/campus` 必须带
`website-path: campus` 头；对 `/index` 带了就回 `{"code": -9000003, "message": "site not exist"}`
——看起来像「这个门户没有岗位」。

10 月 28 日凌晨清理「0 产出」源时用的正是错口径，57 个门户被判成「只有社招」写进
`blocked.jsonl` 并删了 YAML。实际按正确口径重探：**56 个都有岗位**（爱笔 7、沪上阿姨 13、
伯杰医疗 31、黑湖科技 58、正浩创新 163、湖北三宁化工 46…），只有 1 个真的 0 岗。

### 10.3 `feishu_atsx` 没有按 `recruit_types` 过滤

适配器只判断 `recruit_type_of()` 是否为空，没有检查是否在 `source.recruit_types` 里，于是只配了
`[campus, intern]` 的飞书源照样把社招岗写进库（度小满 49 条里 41 条是社招）。北森/大易/大易旧版
都在适配器里做了这个过滤，飞书这一支漏了。现在补齐，纯社招门户显式配 `[campus, intern, social]`。
