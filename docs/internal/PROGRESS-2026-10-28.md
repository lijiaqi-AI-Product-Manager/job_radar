## 1. 发现渠道：把「猜租户名」换掉

先把上一轮的做法量化了一遍，结论是**这条路已经走到头**：

- 40 家公司 × 5 个候选名（全拼 / 首字母 / 品牌英文）× 3 个平台（北森 / 大易 / 飞书）= 600 次请求，**0 命中**，耗时 272 秒。
- 原因不是探测脚本坏了（同一脚本打已知租户 `boe` 1003 岗、`gacrnd` 243 岗、`cntaiping` 1332 岗、`wuxiapptec` 632 岗全部正常），而是**剩下没建源的公司正是前几轮猜不中的残差**。

于是换成「先拿到候选主机，再定归属」。渠道实测结果：

| 渠道 | 结果 | 结论 |
|---|---|---|
| Google / searx 公共实例 | 400 / 403 / 429 | 不可用 |
| Bing（`www` / `cn`） | ICP 备案页、`site:` 被忽略 | 不可用 |
| 百度 / 搜狗 | 「百度安全验证」1428 B / 反爬页 | 不可用 |
| 360 搜索 | 首页几十条可用，第 15 条查询之后整页 3362 B 空结果 | 只能小批量补漏 |
| 今日头条搜索 | 1.4 MB 页面但 `site:` 不生效 | 不可用 |
| DuckDuckGo html | 首个请求 200（20 个租户），之后全 202 anomaly | 不可批量 |
| Common Crawl 索引 | 单 crawl 200–360 个 URL；workday 一次 218 个新主机 | 可用，但老批次已榨干 |
| **公开子域枚举接口** | `zhiye.com` **927**、`hotjob.cn` **320**、`jobs.feishu.cn` **103** 个真实子域 | **本轮唯一跑通的规模化路径** |
| crt.sh / certspotter | 只有 `*.zhiye.com` 通配符证书 | 不可枚举 |
| 被动 DNS（rapiddns / urlscan / hackertarget） | 26 / 27 / 30 条 | 量太小 |
| 北森官网客户案例页 | 244 家客户、未入库 214 家，探完 **0 命中** | 低产，弃用 |

定归属的硬规则（每条都真的挡下过东西）：

1. 门户 `<title>` 必须含中文公司名——标题是「招聘官网」「校园招聘」这类泛化文案的，一律不收；
2. 标题里出现「多品牌 / 共享门户 / 集团门户」的不收（`ys.zhiye.com` 一个池子挂多个品牌）；
3. 已知垃圾 slug 黑名单：`careers`、`campus`、`www`、`wecruit`、`portal-oss`、`itcast1`（「大学招聘门户」无归属）；
4. 同名不同主体要人工判：`camzhaopin`（国机 vs 中国机械总院）、`idea`（IDEA 数字经济研究院 ≠ 数字中国）、
   `arashivision`（影石 Insta360 的标题里有「360」，会被误判成奇虎）；
5. 去重双键：`(adapter, tenant/host)` 与 `(adapter, 公司名去后缀)`，`beisen_host` 与 `beisen` 视为同一适配器。

## 3. 目标池：加 31 个省级行政区

`targets/top_companies.yaml` 新增 `provinces:` 段（808 家地方重点企业，西藏也补了 14 家：
西藏天路、奇正藏药、海思科、藏格矿业…）。行业块 1,117 家与省域块 808 家去重后 **1,655 家**。

- `pipeline/calendar.py` 的 `target_names()` 同时输出行业与省域两组，省域公司标成 `省域·广东` 这类归属；
- 同一家公司（腾讯 = 互联网 + 广东）只算一次，覆盖率分母不重复；
- 站点型子名（「西安」「上海」结尾、母公司已在名单里的）在并入前剔掉，避免把分公司当独立目标。

`scripts/coverage_report.py` 增加分省表，31 个省逐行给目标/已覆盖/覆盖率，零覆盖省份也列出来：

## 4. 这一轮修掉的缺陷

| 缺陷 | 影响 | 修法 |
|---|---|---|
| 紧凑单行 YAML 条目在去重时被整行漏掉 | `- {id: …, company: 海信, params: {…}}` 扫不到 → 海信/奇瑞/恒生被登记成两家公司两条源 | 统一走 `load_sources` 结构化比对（`(adapter, tenant/host)` + `(adapter, 公司名去后缀)` 双键） |
| 大易门户判定只认 `wecruit` | 伊利 `yili.hotjob.cn` 首页 200 但跳到 `/wt/yili/...`，被误判成「没有门户」 | 接受 `/wt/<corp>/` 形态的跳转 |
| 删源后 `companies.jsonl` 仍写 `official_page` | 永辉（飞书 + 北森 `yhchaoshi`）、出门问问、小马智行删掉社招门户后，公司行还在说「官方页可抓」 | 改 `blocked`，`evidence.grade_why` 注明「门户只有社招，校招源已移除」 |
| 226 个 `tmp_*` 临时脚本与抓取快照污染 lint | `ruff check .` 报 816 条，绝大多数来自这些一次性脚本 | 全部清掉，留下的工具脚本收进 `work/` 并逐个过 lint |
