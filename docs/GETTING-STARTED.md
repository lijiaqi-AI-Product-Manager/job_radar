# 让你的助手帮你找工作

job_radar 是给 AI 助手使用的求职搜索技能。你说想去哪里、做什么、有什么条件，助手查询招聘信息、阅读岗位要求，再把候选和来源链接整理给你。覆盖中国校招、实习、社招与招聘日历。

**推荐在有技能或本地工具能力的 Agent 工作模式里使用。** 首次按平台提示接入，之后直接聊需求，不需要记命令或参数。WorkBuddy、千问办公可以从技能导入开始；其他平台怎么选择，见[平台接入说明](PLATFORMS.md)。

## 1. 把这段话发给助手

```text
请帮我接入这个仓库里的 jobradar 求职搜索技能：
https://github.com/lijiaqi-AI-Product-Manager/job_radar
先阅读接入说明，检查当前平台是否支持；完成后，帮我找上海的产品实习，列出岗位要求、来源链接和已注明的截止日期，没写清的信息单独说明。
```

助手会根据所在平台选择技能或 MCP 接入方式。提示需要导入文件时，可从[当前代码 Release](https://github.com/lijiaqi-AI-Product-Manager/job_radar/releases/latest)下载 `jobradar-skill.zip`，在平台的技能页面选择导入；也可导入仓库中的 `skill/jobradar` 文件夹。

导入技能后还需准备查询工具和数据。具备本地执行权限的助手可以按技能中的接入说明完成；平台要求确认安装或下载时，按界面提示操作。普通网页聊天、仅能读取附件或只接受远程 MCP 地址的模式，需要先选择兼容的工作模式，不能仅凭“已读懂说明”视为已接入。

## 2. 确认它真的查到了数据

> 请用 job_radar 查询上海的产品实习，给我几条带原始链接的候选，并说明这次使用的数据时间。

成功的回答应有实际查询结果、来源链接和数据时间。只复述介绍、没有调用工具，或者声称已接入却拿不出查询结果，都还没有完成。真实查询也可能没有候选，此时应说清本次查询条件与数据范围。

## 3. 按自己的条件继续聊

> 我是2027届，想去苏州或无锡做财务，上海不考虑。明确符合届次和没写届次的分开给我。

> 我每周只能实习三天，持续两个月。帮我读岗位要求，分清符合、不符合和没写明的。

> 对比刚才这几个岗位的学历、工作内容和投递入口，指出需要我再去官网确认的地方。

> 帮我看招聘日历，有明确截止日期的先列出来，日期不全的另列。

可以继续说“换成深圳”“排除这家公司”“只看实习”，助手应沿用其余条件。薪资、远程、语言和实习安排以原文证据为准；没有写清不表示不限。投递前打开来源页核对岗位、资格和日期。

## 更新和日常使用

可以直接对助手说“先检查并更新 job_radar 数据，再帮我查”。项目定时采集公开来源，助手使用的是下载到其运行环境的快照。快照时间、某个来源的刷新时间和官网实时状态分别核实。

查询工具无需单独的 API key；你使用的助手可能按其套餐收费。首次需联网下载岗位、正文和日历三库，体积随快照变化；已有有效数据时可以本地查询，打开招聘网站仍需联网。
