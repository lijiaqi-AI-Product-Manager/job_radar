# 覆盖率攻坚计划（2026-10-22）

目标：把 370 家目标公司的岗位覆盖推到尽可能高。本文回答三件事：
**哪些 blocked 是必然的、有哪些替代路径、下一步先做什么。**

## 1. 现状

| 指标 | 数值 |
|---|---|
| 目标公司（`targets/top_companies.yaml`） | 370 |
| 已覆盖（有数据源） | 86 → **95**（本轮 +京东方、海信、名创优品、泡泡玛特、长安汽车、潍柴动力、科大讯飞、汇顶科技、英伟达） |
| 其中 blocked | 7 → 复核后 6（阿里已做） |
| 待侦察 | 277 → 269 |
| 数据源 | 207 → **217** |
| 在招岗位 | 60,721（下一轮 + 阿里 1,075 + 网易 119 + 本轮 3,680） |

> 说明：**100% 覆盖不可能**。原因不是技术不够，而是三类硬约束：
> ① robots 明确禁止（快手）；② 入场即验证码/登录（京东、拼多多、百度、华为）；
> ③ 根本没有公开岗位列表（小米只有品牌页，投递走公众号；277 家里这类占比不低）。
> 在这些约束下，能做的是**把「有公开出口的公司」全部拿下**，其余用招聘日历兜底。

## 2. blocked 判定：必然还是短暂？

判定方法：区分**频控型**（429/5xx/超时/限流 → 重试可解）与**凭证型**（401/403/no-auth/验证码/robots → 每次访问都相同）。
本轮对每家做了至少两次独立复测（间隔数分钟到数天、不同入口）：

| 来源 | 失败现象 | 复测 | 判定 | 依据 |
|---|---|---|---|---|
| 字节跳动 | POST 列表 405、空响应体 | 2026-10-20、10-22 两次，以及带/不带 CSRF、带/不带 Referer 共 5 次 | **必然** | 405 不是频控；GET 回落 SPA；SSR 的 `js-websiteInfo` 里没有 CSRF；页面部署 `verify.snssdk.com` 滑块 |
| 京东 | 页面预加载 `jcap.m.jd.com/requireCaptchaPc.js` | 历史 3 轮 + 本轮复核 | **必然** | 验证码是页面级前置，不是触发式频控；列表接口在验证码前无法确认 |
| 拼多多 | 前端完整验证码流程、robots 403 | 2 轮 | **必然** | 同上 |
| 百度 | 列表接口 `no-auth` | 2 轮 | **必然** | 需要登录态 |
| 华为 | 列表接口 403 | 2 轮 | **必然** | 匿名一律 403 |
| 快手 | `robots.txt: Disallow: /` | — | **政策禁止** | 不是技术问题，按 COMPLIANCE 不做 |
| 小米 | 无岗位列表 | 本轮复核 | **无数据可抓** | 官网只有项目/日程/新闻，投递走公众号 |

结论：**没有一个是「短暂」的**。唯一的例外是限流（429）——目前没有源处于这个状态，`crawl` 已有重试。

## 3. 替代路径矩阵（发散，按可行性排序）

| 来源 | 官方另开入口 | ATS 平台化 | 人工/授权 | 结论 |
|---|---|---|---|---|
| 字节 | 社招 `jobs.bytedance.com/experienced` 同样 405；无 sitemap/RSS | **飞书 ATSX**（同一套，见 §4） | 需官方授权 | 平台突破后一次性解决 |
| 京东 | 社招 `zhaopin.jd.com`（未侦察） | 疑似自研 | 需授权 | 先侦察社招站 |
| 拼多多 | 无 | 自研 | 需授权 | 只能日历兜底 |
| 百度 | 社招 `talent.baidu.com` 同域 | 自研 | 需授权 | 只能日历兜底 |
| 华为 | 社招 `career.huawei.com` 同域 403 | 自研 | 需授权 | 只能日历兜底 |
| 快手 | `campus.kuaishou.cn` robots 禁止 | — | 需授权 | 不做 |
| 小米 | 无列表 | — | 公众号投递 | 日历条目（已有小红书/美的先例） |

补充路径（对所有公司适用）：
- **官方公众号 / 官网公告**：岗位明细拿不到，但「什么项目、什么时候开、去哪投」可以人工核实后进 `calendar.db`——这是当前对字节/京东等已在做的事。
- **第三方聚合（牛客、OfferShow、实习僧）**：数据可能全，但来源不是官方、ToS 与再分发风险高，**按 COMPLIANCE 不做**。
- **官方合作/数据授权**：给招聘方发邮件申请公开接口或数据导出，是唯一能合法拿到验证码类站点数据的方式。

## 4. 平台优先：真正能把覆盖率拉起来的路

覆盖率瓶颈不是「某家公司抓不抓得到」，而是**这家公司用哪个 ATS**。一个平台适配器 = 几十到几百家公司。

| 平台 | 状态 | 覆盖量 | 下一步 |
|---|---|---|---|
| 北森 `*.zhiye.com` | ✅ 已做 | 189 → 191 家 | 持续发现租户（见下） |
| 北森旧版 | ✅ 已做 | 12 家 | 已收口 |
| Moka `*.mokahr.com` | ⛔ | — | 响应 AES 加密，按铁律不逆向 |
| **飞书 ATSX** | 🟡 侦察到接口 | 字节、蔚来、小鹏、理想、货拉拉… | **用 GitHub Actions 的 RENDER 抓一次真实 XHR**（本地沙箱不能跑浏览器） |
| 大易 / gllue | ⬜ 未侦察 | 中等 | 找到租户后按北森模式做 |
| 自研站 | 逐家 | 大疆/OPPO/荣耀/比亚迪/宁德… | 每家一次侦察 |

### 飞书 ATSX 的进展（2026-10-22）

- 确认**蔚来、小鹏、大疆**等用的是飞书 ATSX（`*.jobs.feishu.cn`；大疆还挂了定制域名
  `apply.careers.dji.com/campus-recruitment/dji/143359`），与字节同一套。
- 已找到公开接口：`GET /campus` → 200，SSR 数据在 `#js-websiteInfo`。
- CSRF：`POST /api/v1/csrf/token` → 200，返回 `{"data":{"token":…}}` 并下发 `atsx-csrf-token` cookie（**匿名可拿**，符合铁律 1）。
- 搜索：前端调用 `{base}/api/v1/search/job/posts`，但直接 POST 返回 **405/307**——说明还有一层签名/网关校验，必须看浏览器真实请求头与顺序。
  定制域名（大疆）返回的是另一套后端的 JSON 404（`connect.sid`/`csrfCk`），路径也不一样。
- **结论**：本地沙箱禁止命名管道，Playwright 起不来（`spawn EPERM`）；仓库已有的 `recon-probe` 工作流跑在 Actions 上，有浏览器，用 `RENDER`/`RENDERXHR` 抓一次即可拿到完整请求。这是下一步的最高杠杆动作。

### 北森租户发现（本轮实测有效）

方法：猜 `{slug}.zhiye.com` 或 `{slug}1.zhiye.com`，POST `GetJobAdPageList` 看 `Count`。
租户存在 → 首页 200 + 列表返回 JSON；不存在 → 302 到 `/404`。本轮共探测 135 个候选，命中 8 个独立租户（约 6%）：

| 租户 | 公司 | 岗位数 |
|---|---|---|
| `boe` | 京东方 | 1,050 |
| `hisense1` | 海信 | 1,201 |
| `miniso` | 名创优品 | 57 |
| `popmart` | 泡泡玛特 | 313 |
| `changan` | 长安汽车 | 375 |
| `weichai` | 潍柴动力 | 246 |
| `iflytek` | 科大讯飞 | 884 |
| `miniso1` / `iqiyi` | 名创物流仓 / 爱奇艺线下业务（细分门户，暂未接） | 23 / 13 |

已全部加入 `sources/beisen.yaml` 并真实抓取验证：**3,336 岗入库、JD 3,336 条**。

另有 **旧版门户**（服务端渲染）也值得扫：`goodix.zhiye.com` 首页 200 但新版 API 不返回 JSON，
实际是旧版门户（校招 3 页 / 社招 5 页），走 `beisen_legacy` 适配器即可——已接入汇顶科技
（36 校招 + 64 社招，JD 100%）。判断方法：首页 200 且 `/campus/` 页面里有 `/zpdetail/<id>` 链接。

把这件事固化成工具：`scripts/probe_beisen_tenants.py <slug...>` 或 `--file slugs.txt`，
`--yaml` 直接输出可粘贴的 sources 行。系统化做法：用搜索引擎查 `site:zhiye.com <公司>`，
或从公司官网「校园招聘」入口跳转拿真实 slug，再用脚本校验。

## 6. 下一步（按投入产出排序）

1. **飞书 ATSX**（最高杠杆）：在 Actions 上跑 `recon-probe` 的 `RENDERXHR` 抓真实请求 → 写平台适配器 → 一次覆盖字节 + 蔚来 + 小鹏 + 理想等。
2. **北森租户批量发现**：每轮 +N 家，边际成本最低（本轮 +2 家 1.5 万岗）。
3. **自研站逐家**：大疆、OPPO、荣耀、比亚迪、宁德时代、美的、海尔——按 `docs/recon/TEMPLATE.md` 各写一份侦察。
4. **京东/拼多多/百度/华为**：只在拿到官方授权或发现新的公开出口时再动；否则保持 blocked + 日历兜底。
5. **日历补全到 370 家**：这是唯一能对「所有公司」给出「去哪投、什么时候」的兜底手段。
