# 岗位与正文的观测时间

岗位列表和职位描述分别记录观测时间。`last_seen` 表示最近一次在来源列表中看到记录；详情、岗位对比和全文检索结果的 `text_observed_at` 表示正文最近一次采集所属批次的时间。两者不同是正常情况，投递前应核对原始招聘链接；缺少正文时该时间为空。

`stats.jobs.jd_observation` 报告正文在48小时内的观测数量、较早观测数量和时间范围。`data_as_of` 是最近一次成功来源观测的时间，不代表所有岗位或正文均在该时刻重新读取。

大易来源每轮完整读取配置范围内的岗位列表。只有同一来源、同一岗位ID、标题、招聘类型、发布日期和学历一致，且已有可用正文时，才可复用最多168小时的原文。新岗位、元数据变化、无效正文及超出期限的缓存均需读取详情。列表失败不会使用缓存冒充成功的完整抓取。

详情读取失败时保留已有正文及其原观测时间，不能标为本次新读。完整列表中的岗位状态继续按既有截止日和连续缺席规则处理；正文失败不能被用来推断岗位下架。

该策略减少重复读取，保持源限速。正文复用、列表刷新及软件安装版本分别验证，不能把高覆盖率或测试通过解释为每条岗位都经过实时人工核实。
