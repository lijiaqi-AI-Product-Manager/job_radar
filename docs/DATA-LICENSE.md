# 数据来源与使用说明

代码采用 [MIT License](../LICENSE)。这一代码许可与第三方招聘内容的权利是两回事。

## 来源

岗位标题、职责、要求、招聘日期和原始链接来自公司公开招聘页或允许公开读取的聚合渠道。官方与聚合来源分别标注，原文内容的权利归原权利人。

本项目提供索引、结构化和查询工具，不代表招聘公司，也不对第三方内容授予额外许可。尚未为整个数据集声明独立的 CC0、ODbL 或其他数据许可。

## 使用时核对

- 保留原始来源与数据时间，投递前回到招聘页面确认时效。
- 二次使用或分发第三方内容时，核对来源站点的适用条款和许可。
- 不把快照中的在招状态、缺失日期或字段推断当作官方承诺。
- 数据库不包含投递人信息；凭据与个人联系方式不进入 fixtures。

访问边界与采集要求见 [合规声明](../COMPLIANCE.md)，统计口径见 [覆盖说明](COVERAGE.md)。
