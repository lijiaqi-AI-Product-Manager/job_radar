## 来源与记录类型

- `source_kind: official` 是公司公开招聘来源；`aggregator` 是允许公开读取的第三方来源，分别报告。
- 招聘简章可能覆盖多个职位，必须标记为 `recruitment_notice`。公开快照含 **294 条可见招聘简章记录**，不能将其写成294个独立职位。
- 公告展示截止日与企业实际网申截止日分别核实；前者不用于延长已截止项目。
- 最小入口 URL 属于发现线索。只有归属、访问规则、正文与时效核验通过后才启用源。
- 母集团与子公司不做模糊合并；无法证实的城市、届次、学历或截止日留空。
- 下载快照可能落后于原始页面。新增截止日修复需要后续成功采集才会反映在 Release；投递前应回到原始来源核实。

## 复算

```bash
uv run python scripts/coverage_report.py --json
uv run python scripts/check_compliance.py
uv run python scripts/release_check.py --home <包含三库的数据目录>
```

单独验证 80% 覆盖时运行：

```bash
uv run python scripts/coverage_report.py --json --min-coverage 0.8
```

当前该命令预期退出 1。既有数据质量门禁与覆盖目标分别验收，不能互相替代。最小入口证据在 `targets/coverage_evidence.yaml`，当前源样本在 `targets/source_checks.yaml`；具体平台证据见 [侦察索引](recon/README.md)。

## 查询索引与兼容性

主分支新增 jobs 0003 / text 0002 的 FTS5 trigram 索引；长词保持既有字面子串语义，短词和带通配符的输入回退 LIKE。全量约 29 万岗位副本首次构建约需 1 分钟，两库增加约 199 MB，不构成跨硬件的性能保证。

公开数据库导出为 jobs schema 2 / text schema 1，保留既有客户端可读格式。2.1.0 默认直接查询兼容快照并复用已有索引；需要反复全文查询时，可用 `jobradar update --prepare-index` 在新快照中准备本地索引。工作数据库不被导出操作修改。详见 [发布与兼容性](RELEASE.md)。

覆盖以核实主体为准：广东华兴银行与华夏银行、中国电科三十六所与中国电子分别统计。
