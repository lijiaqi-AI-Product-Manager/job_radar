# 高校公开招聘公告与定向核验

2026-11-02 使用固定项目 UA 在线核验广东工业大学、中山大学、大连海事大学、西安电子科技大学的公开招聘栏目与公告详情。广东工业大学完整索引 65 页、1,300 条；另外三校各读取前 40 页用于发现候选，不把这些局部索引作为完整采集或下架依据。

广东工业大学、大连海事大学、西安电子科技大学的 robots 返回 absent。中山大学 robots 返回 HTTP 403，项目依 RFC 9309 将其作为 unavailable、无适用规则；公告页面本身匿名 HTTP 200，无登录或挑战，未绕过岗位限制。页面未提供独立使用条款链接。只读招聘索引并保留原始出处，不对第三方内容授予额外许可；实际采集仍逐请求检查 robots、跳转与访问状态，保持每源 1 rps。

132 条候选逐条核查，121 条可读、11 条未能验证。核查登记主体、正文、发布日期、学校展示有效期和雇主网申截止日。登记主体是代理公司、不能证明同一实体的子公司、空正文、过期公告和已截止招聘均不用于新增覆盖。23 个目标保留真实登记法人；祖龙娱乐保留北京分公司的范围。对应关系和最小样本见 [公告核验记录](../../targets/university_notice_checks.yaml)及 [源样本](../../targets/source_checks.yaml)。固定目标池的行业、省份与分母均未改变。

这些来源是 `source_kind: aggregator`、`record_kind: recruitment_notice`。一条公告可能包含多个职位，不能将它计作多个单岗。公司名保留实际登记主体，仅为已核实的品牌与法人名称增加别名，不把母集团与子公司做模糊合并。

`notice_ids` 模式完整读取配置中明确的有限公告集合，不重复扫描多年学校索引，也不声称企业全量覆盖。任何一条读取失败会使整源失败，旧状态保留。完整集合成功读取、但全部公告已过期或撤回时，可以接受空集合，按既有连续缺席规则撤回记录；未知雇主截止日仍保持未知。后续新公告须有新的在线核验，不能把旧公告ID当作永久在招证明。

届次只取标题明确且唯一的“届”。招聘年度不自动当成毕业届次；混合校招/实习、多届、开放范围不压成一个年份。雇主明确截止句、年份完整的报名/网申时间段可以提取，多个冲突日期或不合法日期留空，学校展示到期日不用于延长网申。

真实反例：中国银行广东省分行公告的学校展示有效期为 2026-11-04，正文明确“报名截止时间为北京时间2026年10月9日24点”。其雇主截止日为 2026-10-09，不能因展示页面尚未到期而计作当前可投递。测试只保留该截止句与出处，不保留个人联系方式和会话值。

任职要求字段另有 24 个北森、3 个大易租户在同日逐源回读，开关和证据见 [届次核验](../../targets/qualification_checks.yaml)。未核验租户不启用通用正文回填；2026 届按原文保留，不改成 2027 届。
