# 才立方高校公开招聘公告（jysd）

核查日期：2026-10-31，北京时间。**结论：公开列表、公开翻页与公告详情可做；关键词检索需要登录，不使用。** 当前仅核实郑州大学 `job.zzu.edu.cn`，不据平台相似性启用其他学校。

## 公开路径与边界

- [招聘公告首页](https://job.zzu.edu.cn/campus/index) 与站内提供的下一页、[公告详情样例](https://job.zzu.edu.cn/campus/view/id/1019970) 匿名返回 200；固定项目 UA，robots 返回 absent。站点 footer 标注才立方就业。
- 列表 HTML 含标准 zlib/Base64 压缩片段，页面自己的固定字面表达式给出解压、解码与截取步骤。实现只读取这些响应内的公开 HTML，限制解压体积，不执行 JavaScript，不生成请求签名或挑战凭据。
- `keyword` 表单请求转向 `/user/login`，已停止；仅沿匿名首页实际给出的 next 链接浏览，不改写受限检索接口或尝试登录。
- 只读公开招聘文案与索引，不调用举报、收藏、投递、简历、学生或用人单位后台。公开栏目未发现禁止索引的专门条款；不作额外转载许可声明，保留原始链接与来源，遵守下线请求。
- 1 rps，实际请求与重定向受运行时 robots 守卫约束。同一学校完整索引在进程内共享缓存，避免每家公司重复扫描。

## 数据与归属

- 这是**聚合招聘公告通道**，`source_kind: aggregator`。一条公告可能含多个岗位，记录数不等于岗位人数或岗位种类数。
- 列表标题只能发现线索，详情登记主体必须与配置中的全名完全相等；不把子公司改写成母公司，不做任意子串归属。源公司名保留实际全名；新城控股的上海分公司明确保留分支范围。标题里的「金种子计划」不属于「金种子」酒企。
- 只有明确校园/应届招聘的公告参与当前通道。届次只取标题明示值；城市、学历、网申时间缺失保留缺失。
- 学校标注的「过期时间」是公告有效期，**不能当作雇主网申截止日**。过期公告不再作为当前记录；仅明确、唯一的报名/网申截止日可进入 `apply_end`。
- 正文仅取 `aContent`，不混入页眉、页脚、举报弹窗或其他公告。录制样本在内存中裁剪与脱敏后落盘，不保存 cookie、凭据或个人联系方式。

## 初步发现（尚未核实为覆盖）

公开前 60 页共 1,200 条公告，标题命中 36 个未覆盖目标。包括昆仑万维、华润啤酒、华海药业、农夫山泉、新城控股、波克城市、三花智控等；部分实际发布主体为子公司或有歧义，必须逐条核验后才配置启用。来源证据与最终新增数以后续在线样本为准。

本轮另查 SAP / SmartRecruiters：SAP 页面返回 403；SmartRecruiters API 的 robots 明确 `Disallow: /`，未请求岗位 API。公开 API 文档不覆盖站点当前 robots 限制，不使用这些路径。

## 完整验收结果

修正末页 self-link 的判定后，实际完成 **164 页、3,268 条**匿名公开索引；只有分页控件明示当前页等于末页、下一页又指回当前页时才接受终止。真正的中途循环或页数截断仍拒收。

13 个候选逐个复核，**12 个启用、1 个停用**。厦门钨业的公告可读，但正文网申已截止，没有合格当前记录，仍停用，不计入覆盖。空登记主体、前锦等第三方发布主体、未证明归属的子公司、纯图片/外链正文都未据此启用。

启用名单及最小实测证据见 [sources/jysd.yaml](../../sources/jysd.yaml)、[targets/source_checks.yaml](../../targets/source_checks.yaml)。证据按 `recruitment_notice` 记录公告数量，不伪装成单岗数量。完整索引在 12 家之间共享，只读取一次，随后只请求各自匹配的详情；索引不完整不会作为成功结果。

波克城市公告给出的短链接返回 404，未新增官方源；分享跟踪参数从临时记录剔除。当前这批只增长聚合补充覆盖，不能声称官方直连已经净增长。
