# 侦察：内外（beisen · neiwai）

- 侦察日期：2026-10-25
- 侦察人：自研扫街流水线（`work/fast_sweep.py` 发现 + `work/sample_stats.py` 采样）
- **结论：可做**（采样 14 条、归一化 2 条、JD 覆盖率 100%）
- 类型：平台型（多租户）

## 1. 入口与范围
- 公开入口 URL：https://neiwai.zhiye.com/
- 页面标题（实测）：`NEIWAI内外官方招聘`
- 覆盖的招聘类型：校招 / 实习 / 社招
- 预估岗位总量（全量，列表接口 Count 实测）：**14**
- 租户标识：`neiwai`（host：`neiwai.zhiye.com`）

## 2. 合规核查
- robots.txt：本批 108 家抽样实测均为 `User-agent: * / Allow: /`（2026-10-25）；
  北森旧版部分租户 robots.txt 为空文件，记 `not_applicable`
- 服务条款：企业自建公开招聘门户，**无需登录、无签名、无验证码**
- 是否需要登录/验证码/签名：**否**（实测匿名可直取）
- 建议限速：1 rps，同一 host 串行（本项目全局约束）
- 其他风险：无（不含第三方聚合站；不触碰 `necromancer` / `_signature` / `hcm_param` 一类加密参数）

## 3. 取数接口
- 列表接口：`POST https://{tenant}.zhiye.com/api/Jobad/GetJobAdPageList`，body `{"PageIndex":0,"PageSize":100,"KeyWords":"","SpecialType":0,"PortalId":""}`
- 分页：`PageIndex` 从 0/1 起（见上式），每页上限实测 100（北森）/ 50（大易）
- 详情接口（JD 原文）：**无需详情请求**：`Duty`（职责）与 `Require`（要求）直接在列表项里
- 返回结构：`{Code, Count, Data[]}`；关键字段 `Id` / `JobAdName` / `CategoryId` / `Duty` / `Require` / `LocNames`
- 总量字段与终止条件：`Count`；`(PageIndex+1)*PageSize >= Count` 或返回空 `Data`
- 稳定岗位唯一 id：`Id`／`postId`
- 岗位页链接：`https://neiwai.zhiye.com/social/detail?jobAdId={Id}`

## 4. 字段映射
| 我们的字段 | 站点字段 / 提取方式 | 备注 |
|---|---|---|
| source_job_id | `Id`（北森）/ `postId`（大易） | 稳定 |
| title | `JobAdName` / `postName` | 北森标题常带 `(J12345)` 内部编号，需剥离 |
| url | 见第 3 节构造式 | |

| degree_min | `Degree` / `educationStr` | 多数 null |

## 5. 已知陷阱
1. **`CategoryId=<请求参数> 被服务端忽略**：传任何值 Count 都不变，筛选必须在客户端做（需全量翻页）。
2. 本租户实测 CategoryId 分布：`4`:12、`3`:2。
   其中 `4` 未在 `RECRUIT_TYPE` 里映射，会被 `SkipRecord` 丢弃——
   因此「Count」远大于「可入库条数」，对外的岗位数请用采样得到的归一化条数。
3. 采样得到 **归一化 2 条**（上限 300 条采样），JD 覆盖率 **100%**，
   满足项目「JD 正文 ≥90%」契约。
4. 门店/操作岗噪声：若租户是连锁零售，`CategoryId=4` 一类是店员岗，适配器丢弃是**正确**行为。

样本岗位（真实抓取，前 3 条）：

  - `电商运营实习生`（intern，JD 有，132 字）
