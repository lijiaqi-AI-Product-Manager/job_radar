# 招聘日历说明
## 入口分级（2026-10-23 起）

日历条目按「用户点进去能得到多少信息」分三档，
otes 里会写清楚：

| 档 | 特征 | 怎么识别 |
|---|---|---|
| A 招聘专页 | 官方招聘/校招页面，有岗位或网申入口 | jd.status: official_page，notes 无前缀 |
| B 公众号公告 | 官方公众号推文（带发布日期） | source.type: wechat |
| C 仅官网首页 | 只找到官网，没有独立招聘页 | notes 以「【仅官网首页】」开头 |

C 档是为了保证「500 家覆盖」不出现空洞：宁可给一个能点开、能自己找到「人才招聘」的官方入口，
也不要留一条假链接。要只看高质量入口时，按 jd.status=official_page 或 notes 前缀过滤即可。
