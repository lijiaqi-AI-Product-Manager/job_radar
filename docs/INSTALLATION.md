# 安装与版本兼容

日常求职推荐先按[第一次使用](GETTING-STARTED.md)把需求发给助手，由它引导接入。各平台的技能与 MCP 路径见[平台说明](PLATFORMS.md)。以下细节供负责配置的人或助手参考。

需要 Python 3.11+。默认升级当前正式版，最低已验证兼容基线为2.3.1。在实际运行 CLI 或 MCP 的 Python 环境中升级：

```bash
pip install --upgrade "jobsearchradar[mcp]"
jobradar --version
jobradar search --help
jobradar calendar --help
```

仅使用 CLI 可以安装 `jobsearchradar`。包名是 `jobsearchradar`，命令仍为 `jobradar` / `jobradar-mcp`。

备用源码安装不要求本机安装 Git。不同源码修订可能使用同一版本号，因此源码安装使用 `--force-reinstall`：

```bash
pip install --upgrade --force-reinstall "jobsearchradar[mcp] @ https://github.com/lijiaqi-AI-Product-Manager/job_radar/archive/v2.3.6.zip"
```

[PyPI 官方元数据](https://pypi.org/pypi/jobsearchradar/json)提供索引当前版本。
安装目标记录于 [install-target.json](install-target.json)，区分当前源码、最低兼容版本与最近正式索引核验。`verified_on`对应`pypi_version_checked`的实际验证日期。后续文档修改不会改变固定提交的内容。

## 安装后检查

`--version` 应不低于已验证兼容基线 `2.3.1`；`search --help` 应正常退出，并列出 `--deadline-before`；
`calendar --help` 应列出 `--city` 和 `--include-expired`。参数不受支持或帮助报错时，
先核对终端与 MCP 使用的 Python 环境，再按上述命令升级，不要删除筛选条件。

维护者可用 `scripts/check_installed_cli.py --python <目标环境的 Python>` 执行已安装包的离线兼容检查；
核对固定源码安装时另加 `--require-pinned-source`。脚本使用临时样本，不访问招聘网站，
确认导入来自目标环境的已安装包。发布 CI 同样验证构建出的 wheel。

数据另行下载：`jobradar update`。2.3.0优先无损精简正文，默认保留1代，支持`--keep`与`--plain-text`；空间说明见[下载与本地空间](STORAGE.md)。新版在 `JOBRADAR_HOME/snapshots/` 中验证整套三库后切换，
`doctor` 会显示实际 `data_dir`。快照下载成功不代表全部来源已刷新，需同时查看来源新鲜度。
